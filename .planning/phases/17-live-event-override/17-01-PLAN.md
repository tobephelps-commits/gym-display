<task type="auto">
  <name>Task 1: Create LiveEventService</name>
  <files>services/live-event-service.js</files>
  <action>
Create `services/live-event-service.js` following the AnnouncementsService pattern exactly:

**Constructor:** Takes `sheetsClient` and `configLoader` params. Stores refs. Sets `this._activeEvent = null`, `this._events = []`, `this._pollTimer = null`.

**`start()` method:** Call `_refresh()` immediately, then `setInterval(_refresh, 60000)` (60s — same as announcements). Return `this` for chaining.

**`stop()` method:** Clear interval timer.

**`_refresh()` method:**
1. Call `this.sheetsClient.getTabData('LiveEvent')` — returns array of row objects or null
2. If null/empty, set `this._events = []`, `this._activeEvent = null`, return
3. Map rows to event objects: `{ title: row.Title, url: row.URL, start: row.Start, end: row.End, enabled: row.Enabled }`
4. Filter to enabled events: `enabled` field is truthy (case-insensitive "TRUE", "true", "yes", "1")
5. Parse `start` and `end` as dates using the system timezone from `configLoader.get('system.timezone')` — use `new Date(dateString)` for ISO strings, or parse "YYYY-MM-DD HH:MM" manually. Store as Date objects.
6. Find first event where `now >= start && now < end` — set as `this._activeEvent`
7. If no matching event, set `this._activeEvent = null`
8. Wrap in try/catch — log errors but never throw (follows existing service pattern)

**`getActiveEvent()` method:** Returns `this._activeEvent` or null. Shape: `{ title, url, videoId, start, end }` where `videoId` is extracted from URL using the same YouTube URL parsing pattern as video-manager.js (`extractYouTubeId` — copy the regex, don't import from video-manager since it's not exported cleanly).

**`isActive()` method:** Returns `!!this._activeEvent`.

**`getStatus()` method:** Returns `{ configured: !!this.sheetsClient, active: this.isActive(), event: this._activeEvent, eventCount: this._events.length, lastRefresh: this._lastRefresh }`.

**YouTube ID extraction:** Support these URL formats (same as video-manager.js):
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/live/VIDEO_ID`

Export as singleton factory: `module.exports = { create(sheetsClient, configLoader) { return new LiveEventService(sheetsClient, configLoader); } }`

  <name>Task 2: Integrate with ZoneController, server routes, and config</name>

  <action>
**ZoneController changes (services/zone-controller.js):**

1. Add `setLiveEventService(svc)` method — stores ref to LiveEventService (late-binding pattern, same as `setAlertManager()` in zone-health-monitor.js)
2. Modify `getZoneState()`: At the TOP of the method, before normal rotation logic:
   ```
   if (this._liveEventService && this._liveEventService.isActive()) {
     const event = this._liveEventService.getActiveEvent();
     return {
       currentZone: 'live-event',
       nextZone: 'live-event',
       durationMs: 0,  // 0 = no auto-advance
       rotationOrder: this._rotationOrder,
       playFull: false,
       advanceVersion: this._advanceVersion,
       refreshVersion: this._refreshVersion,
       liveEvent: { title: event.title, videoId: event.videoId, url: event.url, endsAt: event.end.toISOString() }
     };
   }
   ```
3. Leave `advanceZone()` unchanged — if kiosk sends advance during live event, `getZoneState()` will just return live-event again on next poll

**Server routes (server.js):**

1. Import and initialize LiveEventService after sheetsClient is created:
   ```
   const liveEventService = require('./services/live-event-service').create(sheetsClient, configLoader);
   liveEventService.start();
   zoneController.setLiveEventService(liveEventService);
   ```
2. Add `GET /api/live-event` route (public, no auth):
   ```
   res.json(liveEventService.getStatus())
   ```
3. In the existing `GET /api/admin/status` handler, add `liveEvent: liveEventService.getStatus()` to the response object
4. Add liveEventService to graceful shutdown: `liveEventService.stop()` alongside other service stops
5. Add `POST /api/admin/refresh/live-event` admin route: calls `liveEventService._refresh()` and returns `{ message: 'Live event data refreshed' }`

**Config loader (services/config-loader.js):**

1. Add `'live-event'` to the `VALID_ZONE_NAMES` array — this prevents validation errors if someone adds it to rotation_order (though live-event won't normally be in rotation_order since it's an override)

**Config example (config.example.yaml):**

Add a comment section near the sheets config explaining the LiveEvent tab:
```yaml
# Live Events (via Google Sheets "LiveEvent" tab)
# Columns: Title, URL (YouTube Live), Start (YYYY-MM-DD HH:MM), End (YYYY-MM-DD HH:MM), Enabled (TRUE/FALSE)
# When an enabled event's time window includes now, rotation is overridden with fullscreen YouTube Live
# Multiple events can be scheduled; first matching active event wins
# Times are interpreted in the system.timezone setting
```
