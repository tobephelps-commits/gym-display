**app.js changes:**

1. Add state variables at the top (near existing state):
   ```
   let liveEventActive = false;
   let liveEventPlayer = null;
   let liveEventVideoId = null;
   ```

2. Modify the zone polling logic (the function that polls `/api/zones` every 2 seconds). Currently it checks `advanceVersion` to detect admin-triggered advances. Add live event detection:
   ```
   // After fetching zone state:
   if (state.currentZone === 'live-event' && state.liveEvent) {
     if (!liveEventActive) {
       enterLiveEventMode(state.liveEvent);
     }
   } else if (liveEventActive) {
     exitLiveEventMode();
   }
   ```
   When in live event mode, do NOT call `advanceZone()` or update `currentIndex` — the zone poll just maintains the live event state.

3. Add `enterLiveEventMode(event)` function:
   - Set `liveEventActive = true`
   - Clear `rotationTimer` (stop auto-advance)
   - Hide all existing zones: `document.querySelectorAll('.zone').forEach(z => z.classList.add('hidden'))`
   - Show `zone-live-event`: `document.getElementById('zone-live-event').classList.remove('hidden')`
   - Set title: `document.getElementById('live-event-title').textContent = event.title`
   - Show overlay, set timeout to add 'fade-out' class after 10 seconds
   - If `event.videoId !== liveEventVideoId`, create YouTube player:
     ```
     destroyLiveEventPlayer();
     liveEventVideoId = event.videoId;
     var playerDiv = document.createElement('div');
     playerDiv.id = 'live-yt-player';
     document.getElementById('live-yt-container').appendChild(playerDiv);
     liveEventPlayer = new YT.Player('live-yt-player', {
       width: '100%',
       height: '100%',
       videoId: event.videoId,
       playerVars: {
         autoplay: 1, controls: 0, modestbranding: 1, rel: 0,
         fs: 0, iv_load_policy: 3, disablekb: 1, playsinline: 1, enablejsapi: 1
       },
       events: {
         onReady: function(e) { e.target.setVolume(80); }
         // NO onStateChange ENDED handler — live streams don't end via player state
         // Override ends when server says event time window is over
       }
     });
     ```

4. Add `exitLiveEventMode()` function:
   - Set `liveEventActive = false`
   - Call `destroyLiveEventPlayer()`
   - Set `liveEventVideoId = null`
   - Hide `zone-live-event`
   - Resume normal rotation: call `showZone(rotationOrder[currentIndex])` and `scheduleNext()`

5. Add `destroyLiveEventPlayer()` function:
   - If `liveEventPlayer`, try `liveEventPlayer.destroy()`, catch errors
   - Set `liveEventPlayer = null`
   - Clear `live-yt-container` innerHTML

6. Modify `advanceZone()`: Add early return if `liveEventActive` is true — don't advance during live event.

7. Modify `showZone()`: Add `'live-event'` to the zone list that gets hidden/shown (it won't be in normal rotation, but just in case).

**Important:** Do NOT add 'live-event' to `rotationOrder` — it's not a normal zone. It's an override that takes over when the server says so. The existing rotation continues to track its position; when the override ends, rotation resumes from where it was.

**Admin JS — update Dashboard polling (public/admin/admin.js):**

In the existing Dashboard status polling callback (where it processes `/api/admin/status` response), add:
```js
// Live Event status
if (data.liveEvent) {
  var badge = document.getElementById('live-event-badge');
  var details = document.getElementById('live-event-details');
  if (data.liveEvent.active && data.liveEvent.event) {
    badge.textContent = 'LIVE NOW';
    badge.className = 'badge live';
    document.getElementById('live-event-title-admin').textContent = data.liveEvent.event.title;
    document.getElementById('live-event-ends').textContent = new Date(data.liveEvent.event.end).toLocaleTimeString();
    details.classList.remove('hidden');
  } else if (data.liveEvent.eventCount > 0) {
    badge.textContent = 'Scheduled';
    badge.className = 'badge scheduled';
    details.classList.add('hidden');
  } else {
    badge.textContent = 'No Event';
    badge.className = 'badge none';
    details.classList.add('hidden');
  }
}
```
