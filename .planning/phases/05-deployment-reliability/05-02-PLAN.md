  <files>scripts/hdmi-cec.sh, scripts/gym-cec-off.service, scripts/gym-cec-off.timer, scripts/gym-cec-on.service, scripts/gym-cec-on.timer</files>
  <action>
**scripts/hdmi-cec.sh** — CEC control script:
- Shebang: #!/bin/bash
- Accept argument: "on" or "off"
- "off": `echo 'standby 0' | cec-client -s -d 1` (send standby to TV address 0)
- "on": `echo 'on 0' | cec-client -s -d 1` (send power on to TV address 0)
- Log action with timestamp to stdout (captured by journalctl)
- Exit 0 on success, exit 1 on invalid argument with usage message

**scripts/gym-cec-off.service** — TV standby service:
- [Unit]: Description="Turn TV off via HDMI CEC"
- [Service]: Type=oneshot, ExecStart=/home/pi/gym-display/scripts/hdmi-cec.sh off, User=pi

**scripts/gym-cec-off.timer** — Nightly off timer:
- [Unit]: Description="Turn TV off at 9pm"
- [Timer]: OnCalendar=*-*-* 21:00:00, Persistent=true
- [Install]: WantedBy=timers.target

**scripts/gym-cec-on.service** — TV wake service:
- [Unit]: Description="Turn TV on via HDMI CEC"
- [Service]: Type=oneshot, ExecStart=/home/pi/gym-display/scripts/hdmi-cec.sh on, User=pi

**scripts/gym-cec-on.timer** — Morning on timer:
- [Unit]: Description="Turn TV on at 4:30am"
- [Timer]: OnCalendar=*-*-* 04:30:00, Persistent=true
- [Install]: WantedBy=timers.target

Use `cec-client` from the `cec-utils` package (installed by setup.sh).
The `-s` flag makes cec-client use stdin, `-d 1` reduces debug output.

<task type="auto">

  <files>scripts/gym-display.logrotate</files>
  <action>
Create scripts/gym-display.logrotate — logrotate config for journald and app logs:

```
/home/pi/gym-display/logs/*.log {
    daily
    missingok
    rotate 7
    compress
    delaycompress
    notifempty
    create 0640 pi pi
}
```

Note: Since the app uses journalctl (stdout/stderr from systemd), the primary log rotation is handled by systemd's built-in journal size limits. This logrotate config is for any file-based logs.

Also create a journald size limit snippet that setup.sh will install:
Add a comment at the top of the logrotate file documenting that setup.sh should configure journald with:
- SystemMaxUse=100M (limit journal to 100MB)
- MaxRetentionSec=7day (keep 7 days of logs)

This prevents SD card fill-up from journald logs. The setup.sh script (Plan 05-03) will handle writing /etc/systemd/journald.conf.d/gym-display.conf.
