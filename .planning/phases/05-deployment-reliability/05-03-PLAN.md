  <action>
Create scripts/setup.sh — a bash script that provisions a fresh Raspberry Pi OS Lite (Bookworm 64-bit) for the gym display system. Must run as root (sudo).

Script structure:

1. **Header and safety:**
   - #!/bin/bash, set -e (exit on error)
   - Check running as root: `if [ "$EUID" -ne 0 ]; then echo "Run with sudo"; exit 1; fi`
   - Detect the real user (SUDO_USER) for non-root operations
   - Print banner with what the script will do

2. **System updates:**
   - apt update && apt upgrade -y

3. **Install Node.js 20 LTS:**
   - Install via NodeSource: `curl -fsSL https://deb.nodesource.com/setup_20.x | bash -`
   - apt install -y nodejs

4. **Install display and kiosk dependencies:**
   - apt install -y chromium-browser xserver-xorg x11-xserver-utils xinit unclutter
   - These provide: Chromium, X11 server, display utilities, cursor hiding

5. **Install CEC utilities:**
   - apt install -y cec-utils

6. **Install application dependencies:**
   - cd /home/$SUDO_USER/gym-display && npm install --production
   - Run as the real user: `sudo -u $SUDO_USER npm install --production`

7. **Configure autologin to console:**
   - Create /etc/systemd/system/getty@tty1.service.d/override.conf
   - ExecStart=-/sbin/agetty --autologin $SUDO_USER --noclear %I $TERM

8. **Configure X11 autostart on login:**
   - Add `[ -z "$DISPLAY" ] && [ "$(tty)" = "/dev/tty1" ] && startx -- -nocursor` to user's .bash_profile (if not already present)
   - Create/update .xinitrc to run the kiosk: `exec /home/$SUDO_USER/gym-display/scripts/start-kiosk.sh`

9. **Install systemd services:**
   - Copy scripts/gym-display.service to /etc/systemd/system/
   - Copy scripts/gym-kiosk.service to /etc/systemd/system/
   - Copy scripts/gym-cec-off.service, gym-cec-off.timer to /etc/systemd/system/
   - Copy scripts/gym-cec-on.service, gym-cec-on.timer to /etc/systemd/system/
   - Replace /home/pi with /home/$SUDO_USER in copied files using sed (support non-pi usernames)
   - systemctl daemon-reload
   - systemctl enable gym-display gym-kiosk gym-cec-off.timer gym-cec-on.timer

10. **Configure journald log limits:**
    - mkdir -p /etc/systemd/journald.conf.d
    - Write gym-display.conf: SystemMaxUse=100M, MaxRetentionSec=7day
    - systemctl restart systemd-journald

11. **Install logrotate config:**
    - Copy scripts/gym-display.logrotate to /etc/logrotate.d/gym-display
    - Update paths with sed for actual user home directory

12. **Set config.yaml permissions:**
    - chmod 600 /home/$SUDO_USER/gym-display/config.yaml
    - chown $SUDO_USER:$SUDO_USER /home/$SUDO_USER/gym-display/config.yaml

13. **Make scripts executable:**
    - chmod +x scripts/start-kiosk.sh scripts/hdmi-cec.sh

14. **Install Raspberry Pi Connect (rpi-connect-lite):**
    - apt install -y rpi-connect-lite
    - systemctl enable --now rpi-connect-lite
    - Print message: "RPi Connect installed. Run 'rpi-connect signin' to link to your Raspberry Pi account."

15. **Final output:**
    - Print summary of what was installed
    - Print next steps: edit config.yaml with credentials, reboot to start
    - Print management commands (systemctl restart, journalctl, etc.)

Make script idempotent — safe to run multiple times (use mkdir -p, check before appending to files, etc.).
