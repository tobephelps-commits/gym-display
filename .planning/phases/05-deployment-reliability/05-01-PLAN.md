  <name>Task 1: Create systemd service files and production server binding</name>
  <files>scripts/gym-display.service, scripts/gym-kiosk.service, server.js</files>
  <action>
Create two systemd unit files in scripts/:

**scripts/gym-display.service** — Node.js server service:
- [Unit]: Description="Gym Display Server", After=network-online.target, Wants=network-online.target
- [Service]: Type=simple, User=pi, WorkingDirectory=/home/pi/gym-display, ExecStart=/usr/bin/node server.js, Restart=always, RestartSec=5, Environment=NODE_ENV=production
- [Install]: WantedBy=multi-user.target
- Add StandardOutput=journal, StandardError=journal for journalctl logging

**scripts/gym-kiosk.service** — Chromium kiosk service:
- [Unit]: Description="Gym Display Kiosk", After=gym-display.service, Wants=gym-display.service
- [Service]: Type=simple, User=pi, Environment=DISPLAY=:0, ExecStart=/home/pi/gym-display/scripts/start-kiosk.sh, Restart=always, RestartSec=10
- [Install]: WantedBy=graphical.target

**server.js modification** — Production bind address:
- Check `process.env.NODE_ENV === 'production'` to determine bind address
- Production: bind to '127.0.0.1' (security — no network exposure)
- Development (default): bind to '0.0.0.0' (accessible from network for testing)
- Log which address the server is binding to

<task type="auto">
  <name>Task 2: Create Chromium kiosk launcher script</name>
  <files>scripts/start-kiosk.sh</files>
  <action>
Create scripts/start-kiosk.sh — a bash script that launches Chromium in kiosk mode:

1. Shebang: #!/bin/bash
2. Wait for the Node.js server to be ready: loop with curl to localhost:3000/api/health until it returns 200 (max 30 retries, 2s sleep between)
3. Set up X11 environment:
   - xset s off (disable screensaver)
   - xset -dpms (disable power management)
   - xset s noblank (no screen blanking)
   - unclutter -idle 0.5 -root & (hide mouse cursor)
4. Launch Chromium with flags from Design Document:
   - --kiosk (full screen, no UI chrome)
   - --noerrdialogs (suppress error dialogs)
   - --disable-infobars (no "controlled by automation" bar)
   - --disable-session-crashed-bubble (no crash recovery dialog)
   - --incognito (no persistent browser state)
   - --autoplay-policy=no-user-gesture-required (critical for video autoplay)
   - --disable-features=TranslateUI (no translation popups)
   - --check-for-update-interval=31536000 (disable update checks)
   - --disable-pinch (no zoom gestures)
   - --overscroll-history-navigation=0 (no swipe navigation)
   - --disable-gpu-compositing (avoid GPU issues on Pi)
   - Point to http://localhost:3000
5. Use `chromium-browser` command (Raspberry Pi OS package name)
6. Make script executable (note in verify)

Do NOT use `google-chrome` or `chromium` — Raspberry Pi OS Bookworm provides `chromium-browser`.
  </action>
  <verify>Confirm scripts/start-kiosk.sh exists, starts with #!/bin/bash, contains the health check loop, xset commands, unclutter, and chromium-browser with all required flags. File should be created with intent to be chmod +x on the Pi.</verify>
  <done>start-kiosk.sh waits for server health, disables screen blanking, hides cursor, and launches chromium-browser in full kiosk mode with all required flags</done>
</task>
