# Phase 4: MindBody Integration - Context

**Gathered:** 2026-02-21
**Status:** Ready for research

<vision>
## How This Should Work

The roster zone is a live check-in board on the gym TV. When a class is running, the display shows who's checked in — names appearing as athletes scan in through MindBody. It should feel like a digital check-in board on the wall, always reflecting who's actually in the building right now.

The layout is a big, clean grid of names with the class name at the top. Simple and readable from across the gym floor — no clutter, no extra info. Just the class and the athletes.

During class times, the rotation should boost the roster zone so it shows more frequently. The display knows what class is happening and adjusts accordingly.

</vision>

<essential>
## What Must Be Nailed

- **Always current** — The roster must reflect who's actually checked in RIGHT NOW. No stale data, no showing yesterday's class.
- **Readability from distance** — Names need to be big and clear enough to read from 20+ feet away on the gym floor.
- **Class awareness** — The display should know what class is happening and boost the roster zone during class times.

</essential>

<specifics>
## Specific Ideas

- Just names — class name at top, athlete names below in a clean grid/list
- No extra athlete info needed (no photos, no stats, no check-in times)
- Keep it simple and uncluttered

</specifics>
