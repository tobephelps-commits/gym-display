**showRosterState(stateId)** function — show one roster-state element, hide all others (same pattern as showWodElement):
```javascript
function showRosterState(stateId) {
  var states = document.querySelectorAll('.roster-state');
  states.forEach(function(el) { el.classList.add('hidden'); });
  var target = document.getElementById(stateId);
  if (target) { target.classList.remove('hidden'); }
}
```

**updateRosterDisplay(data)** function:
- If !data or !data.classInfo: show 'roster-empty' state, return
- Show 'roster-display' state
- Set #roster-class-name textContent to data.classInfo.name || 'Class'
- Set #roster-class-meta to coach name if available (e.g., "Coach: Sarah" or just the time range)
- Clear #roster-grid, then for each athlete in data.athletes, create a div.roster-athlete with textContent = athlete name, append to grid
- Set #roster-count to `${data.count} athlete${data.count !== 1 ? 's' : ''} checked in`
- Apply compact/dense class based on athlete count: >15 athletes → roster-grid-compact, >25 → roster-grid-dense, otherwise remove both

**pollRoster()** function:
- Fetch /api/roster
- On success: call updateRosterDisplay(data), store rosterLastData = data
- On error: if no previous data, show 'roster-error'. If previous data exists, keep showing it (stale data is better than error).

**onRosterZoneActive()** function:
- Immediately poll roster
- Start polling every 10 seconds: rosterPollTimer = setInterval(pollRoster, 10000)
- (10s is frontend poll rate; backend polls MindBody API at 60s intervals. Frontend polls backend's cached data more frequently for responsiveness.)

**onRosterZoneInactive()** function:
- Clear rosterPollTimer if set

**Wire into showZone()** — add roster zone activation/deactivation alongside existing WOD and video patterns:
```javascript
// In showZone(), add:
if (zoneName === 'roster') {
  onRosterZoneActive();
} else if (previousZone === 'roster') {
  onRosterZoneInactive();
}
```

**Initialize roster state** in init(): show 'roster-loading' state initially. After first config fetch, check if mindbody is configured. If not configured, show 'roster-error' with "Roster unavailable" message.

Add to fetchConfig(): read `config.mindbody.configured` boolean for display state awareness.
