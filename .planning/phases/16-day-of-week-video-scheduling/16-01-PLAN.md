<task type="auto">
  <name>Task 1: Add day-of-week filtering to VideoManager</name>
  <files>services/video-manager.js</files>
  <action>
Add a helper function `isScheduledForToday(daysStr)` at module level (near the other helpers):
- Takes a string like "Mon,Wed,Fri" or empty/undefined
- Returns true if blank/undefined/empty (backward compatible — plays every day)
- Parses comma-separated day abbreviations (Mon,Tue,Wed,Thu,Fri,Sat,Sun), case-insensitive, trimmed
- Gets current day using the system timezone from config (`configLoader.getConfig().system.timezone` or fallback to system default). Use `new Date().toLocaleDateString('en-US', { weekday: 'short', timeZone })` to get "Mon", "Tue", etc.
- Returns true if current day matches any day in the list

Apply the filter in two places:

1. `_buildPlaylistFromSheets()` — after the enabled check (line 92), add:
   `if (!isScheduledForToday(row.days)) continue;`

2. `_buildPlaylist()` config fallback path — after the enabled check (line 121), add:
   `if (!isScheduledForToday(entry.days)) continue;`

Important: The `_checkSheetsUpdate()` method compares playlist IDs to detect changes. Since day filtering happens during build, the playlist will naturally change at midnight when the day rolls over. The next 60-second check will pick up the change. No additional logic needed there — the existing comparison mechanism handles it.

Log when day filtering excludes videos: `[VideoManager] Day filter: ${excluded} videos excluded for ${currentDay}` (log once during _buildPlaylist, not per-video).
  </action>
  <verify>
Start the server with `node server.js` and confirm:
- No startup errors
- Log shows playlist loaded with correct count
- `curl http://localhost:3000/api/videos` returns playlist (only videos scheduled for today or with no day restriction)
- Videos with a `days` value not including today are excluded
- Videos with no `days` value are included (backward compatible)
  </verify>
  <done>
VideoManager filters videos by day-of-week from both Sheets and config sources. Videos without day restrictions play every day. Timezone-aware using system.timezone config.
  </done>
