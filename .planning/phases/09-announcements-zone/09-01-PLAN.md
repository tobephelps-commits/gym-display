<task type="auto">
  <name>Task 1: Create AnnouncementsService reading Sheets "Announcements" tab</name>
  <files>services/announcements-service.js</files>
  <action>
Create `services/announcements-service.js` as a singleton class following the exact LeaderboardService pattern:

- Import `sheetsClient` and `configLoader`
- Constructor: initial refresh, 60-second setInterval refresh, configLoader.onConfigChange listener
- `_refreshFromSheets()`:
  - Read `sheetsClient.getTabData('Announcements')`
  - If no data, set `{ active: false, announcements: [], lastUpdated: null }`
  - Filter rows where `Active` column is truthy (case-insensitive: "TRUE", "true", "yes", "1") — same pattern as VideoManager/ReelsFetcher enabled check
  - Map each active row to: `{ title: row.Title, body: row.Body, priority: row.Priority || 'normal' }`
  - Skip rows with missing Title AND Body (warn like leaderboard does for missing Name/Team)
  - Sort by priority: "urgent" first, then "normal" (simple two-tier sort)
  - Set `{ active: true, announcements: [...], count: N, lastUpdated: ISO string }`
- `getAnnouncements()` — returns the data structure
- `isActive()` — returns boolean (has active announcements)
- Export singleton instance

Sheets "Announcements" tab expected columns: Title, Body, Active, Priority (optional, defaults to "normal")
  </action>
  <verify>node -e "require('./services/announcements-service.js')" exits without error</verify>
  <done>AnnouncementsService singleton created, reads Sheets tab, filters active announcements, refreshes every 60s</done>
</task>

<task type="auto">
  <name>Task 2: Add API endpoint, config, and zone-controller integration</name>
  <files>server.js, config.example.yaml, services/zone-controller.js</files>
  <action>
Follow the exact leaderboard integration pattern from Phase 8:

**server.js:**
- Import `announcements-service` at top alongside leaderboard-service
- Add `GET /api/announcements` endpoint returning `announcementsService.getAnnouncements()`
- Add `announcements: { active: announcementsService.isActive() }` to the sanitized `/api/config` response (same spot as leaderboard.active)

**config.example.yaml:**
- Add `announcements` to rotation_order: `["wod", "video", "roster", "leaderboard", "announcements"]`
- Add announcements zone config section with comments explaining the Sheets tab format:
  ```yaml
  # Announcements Zone: Reads from Sheets "Announcements" tab
  # Tab columns: Title, Body, Active (TRUE/FALSE), Priority (optional: urgent/normal)
  # Zone auto-skips when no active announcements or Sheets not configured
  announcements:
    duration_seconds: 60
  ```

**services/zone-controller.js:**
- Add `'announcements'` to both default rotation_order arrays (constructor and onConfigChange)
- Add `announcements` to `_extractDurations()`: `announcements: ((zones.announcements && zones.announcements.duration_seconds) || 60) * 1000`
  </action>
