<task type="auto">
  <name>Task 2: Wire up announcements zone in app.js</name>
  <files>public/app.js</files>
  <action>
Follow the leaderboard zone lifecycle pattern exactly:

**State variables (add near leaderboard state vars):**
```javascript
var announcementsPollTimer = null;
var announcementsLastData = null;
var announcementsConfigured = false;
```

**Helper functions:**
- `showAnnouncementsState(stateId)` — same pattern as showLeaderboardState: query `.announcements-state`, hide all, show target
- `updateAnnouncementsDisplay(data)` — if no data or not active or empty announcements array, show empty state. Otherwise:
  - Show display state
  - Clear and populate `#announcements-list` with cards:
    - Each card: div.announcement-card with data-priority attribute
    - If priority === 'urgent', add class 'announcement-urgent'
    - Title div.announcement-title (only if title exists)
    - Body div.announcement-body (only if body exists)
  - If >4 announcements, add 'announcements-compact' class to list container
- `pollAnnouncements()` — fetch `/api/announcements`, call updateAnnouncementsDisplay, cache in announcementsLastData. On error, keep stale data (same pattern as leaderboard)

**Zone lifecycle:**
- `onAnnouncementsZoneActive()` — if not configured, skip (setTimeout advanceZone, 0). Fetch /api/announcements; if no active announcements, advanceZone(). Otherwise render and start 30-second poll interval.
- `onAnnouncementsZoneInactive()` — clearInterval poll timer

**Integration points (matching leaderboard pattern):**
- `showZone()`: add deactivation for 'announcements' (onAnnouncementsZoneInactive) and activation (onAnnouncementsZoneActive)
- `fetchConfig()`: read `config.announcements.active` into `announcementsConfigured`, add `durations.announcements` extraction
- `init()`: read initial `announcementsConfigured` from config, set initial state (empty if not configured, loading if configured), add `durations.announcements` extraction
