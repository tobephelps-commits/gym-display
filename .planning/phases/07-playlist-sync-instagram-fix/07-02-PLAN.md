<task type="auto">
  <name>Task 1: Add yt-dlp download capability for Sheets playlist URLs</name>
  <files>services/reels-fetcher.js</files>
  <action>
Modify ReelsFetcher to download non-YouTube video URLs from the Sheets "Playlist" tab using yt-dlp, replacing instaloader profile scraping as the primary reel source.

**Sheets tab format** (same as Plan 01):
- `url` — Video URL (Instagram reel, TikTok, direct .mp4, etc.)
- `title` — Display title
- `enabled` — "TRUE"/"true"/"yes"/"1" means enabled

**Implementation:**

1. Import `sheetsClient` from `./sheets-client`

2. Add helper `_isYouTubeUrl(url)`:
   - Return true if URL matches YouTube patterns (youtube.com, youtu.be)
   - These are handled by VideoManager, NOT ReelsFetcher

3. Add helper `_isEnabledRow(row)`:
   - Check row.enabled is truthy: "TRUE", "true", "yes", "1" (case-insensitive)
   - Return boolean

4. Add `_getReelUrlsFromSheets()` method:
   - Call `sheetsClient.getTabData('Playlist')`
   - If null/empty or Sheets not configured, return `null` (signals: use instaloader fallback)
   - Filter rows where: `row.url` exists, `_isEnabledRow(row)`, NOT `_isYouTubeUrl(row.url)`
   - Return array of `{url, title}` objects
   - Return empty array if tab exists but no non-YouTube URLs (signals: no reels to download)

5. Add `_downloadWithYtDlp(url, outputFilename)` method:
   - Use `execFile` to run yt-dlp: `yt-dlp -o {CACHE_DIR}/{outputFilename}.%(ext)s --format mp4 --no-playlist {url}`
   - Use `yt-dlp` command name (installed via pip3 on Pi, or as binary)
   - Timeout: 120 seconds
   - Return true on success, false on failure (log error, don't throw)
   - On Windows dev: use `yt-dlp` (same command name works if installed via pip)

6. Add `_generateFilename(url)` method:
   - Create a stable filename from URL hash: `require('crypto').createHash('md5').update(url).digest('hex').slice(0, 12)`
   - This ensures same URL always maps to same filename (no re-downloads)

7. Add `_runSheetsDownload()` method (replaces `_runInstaloader()` when Sheets active):
   - Call `_getReelUrlsFromSheets()`
   - Get list of already-cached filenames from `_reelsList`
   - For each URL: compute filename, skip if already in cache/reels/ (check fs.existsSync)
   - For new URLs: call `_downloadWithYtDlp(url, filename)`
   - Log: `[ReelsFetcher] Downloading reel: {title} ({url})`
   - After downloads: remove cached files whose URLs are no longer in Sheets (prune stale)
   - Track URL→filename mapping in `this._urlFileMap` (Map object) for stale detection

8. Modify `runFetchCycle()`:
   - Try `_getReelUrlsFromSheets()` first
   - If returns non-null (Sheets active): use `_runSheetsDownload()`, set `this._source = 'sheets'`
   - If returns null (no Sheets): use existing `_runInstaloader()`, set `this._source = 'instaloader'`
   - Rest of method unchanged (_cleanNonVideos, _scanCachedReels, prune, update lastFetch)

9. Add `getSource()` method returning `this._source` ('sheets' or 'instaloader')

10. Update `getStatus()`:
    - Add `source` field to returned object

**Important:** Do NOT remove `_runInstaloader()` — keep it as fallback for when Sheets is not configured. The existing instaloader path must continue working unchanged.

**Error handling for yt-dlp not installed:**
- In `_downloadWithYtDlp()`, catch ENOENT error (command not found)
- Log warning once: `[ReelsFetcher] yt-dlp not found — install with: pip3 install yt-dlp`
- Set `this._ytDlpAvailable = false` to avoid repeated attempts
- Return false
