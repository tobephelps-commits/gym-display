<task type="auto">
  <name>Task 1: Update VideoManager to read YouTube playlist from Sheets</name>
  <files>services/video-manager.js</files>
  <action>
Modify VideoManager to use Google Sheets "Playlist" tab as primary playlist source, falling back to config.yaml `videos[]` array.

**Sheets tab format** (columns in first row as headers):
- `url` — YouTube or video URL
- `title` — Display title
- `enabled` — "TRUE", "true", "yes", or "1" means enabled; anything else means disabled

**Implementation:**
1. Import `sheetsClient` from `./sheets-client`
2. Add `_buildPlaylistFromSheets()` method:
   - Call `sheetsClient.getTabData('Playlist')` — returns array of row objects
   - If result is non-empty array, filter rows where:
     - `row.url` exists and is a valid YouTube URL (use existing `extractYouTubeId()`)
     - `row.enabled` is truthy (check for "TRUE", "true", "yes", "1" — case-insensitive)
   - Map to `{videoId, title, url}` objects (same format as config-based playlist)
   - Return the array (empty array means "Sheets has Playlist tab but no YouTube URLs")
   - Return `null` if Sheets not configured or no "Playlist" tab (signals: use config fallback)
3. Modify `_buildPlaylist()`:
   - Try `_buildPlaylistFromSheets()` first
   - If returns non-null (even empty array), use it and set `this._source = 'sheets'`
   - If returns null, fall back to existing config.yaml logic and set `this._source = 'config'`
   - Log the source: `[VideoManager] Playlist loaded from ${source}: ${count} videos`
4. Add `getSource()` method returning `this._source` ('sheets' or 'config')
5. Add periodic Sheets sync: in constructor, set up a 60-second interval that calls `_checkSheetsUpdate()`:
   - Call `_buildPlaylistFromSheets()`
   - Compare video IDs with current playlist
   - If changed, rebuild playlist and log changes
   - This catches Sheets poll updates between config changes
6. Keep existing config change listener (handles config.yaml changes AND Sheets reconnection)

**Important:** Non-YouTube URLs in the Playlist tab should be silently skipped (they're handled by ReelsFetcher in Plan 02). Do NOT warn about non-YouTube URLs — only warn about malformed YouTube URLs.
  </action>
  <verify>
    - `node -e "require('./services/video-manager')"` loads without error
    - When Sheets not configured: playlist falls back to config.yaml videos (existing behavior preserved)
    - VideoManager logs source as 'config' when Sheets unavailable
  </verify>
  <done>

    - Falls back to config.yaml videos[] when Sheets not configured or no Playlist tab
    - Periodic sync picks up Sheets changes within 60 seconds
    - getSource() returns 'sheets' or 'config'
    - Non-YouTube URLs silently skipped
  </done>
