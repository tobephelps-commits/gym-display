<task type="auto">
  <name>Task 2: Create zone controller service and frontend rotation engine</name>
  <files>services/zone-controller.js, public/app.js, server.js</files>
  <action>
    1. Create services/zone-controller.js:
       - Import config-loader
       - Maintain state: currentZoneIndex, rotationOrder (from config.zones.rotation_order), zone durations
       - getZoneState() returns { currentZone: "wod"|"video"|"roster", nextZone, durationMs, rotationOrder }
       - advanceZone() moves to next zone in rotation order
       - Listen for config changes to update rotation order and durations dynamically
       - Export getZoneState, advanceZone

    2. Update server.js to add zone API endpoints:
       - GET /api/zones/current — returns zone-controller.getZoneState()
       - POST /api/zones/advance — manually advance zone (useful for testing)

    3. Create public/app.js — the frontend rotation engine:
       - On load, fetch /api/config to get zone config (rotation_order, durations)
       - State machine managing current zone: track which zone div is active
       - showZone(zoneName): remove 'active' class from all zones, add 'active' to target zone (triggers CSS crossfade)
       - Timer-based rotation: after zone's configured duration, advance to next zone
         - WOD: zones.wod.duration_seconds * 1000
         - Video: zones.video.fallback_seconds * 1000 (full video logic comes in Phase 3)
         - Roster: zones.roster.duration_seconds * 1000
       - Poll /api/config every 30 seconds to pick up hot-reload changes (rotation order, durations)
       - On config change: update durations for next cycle (don't interrupt current zone mid-display)
       - Console log each transition: "Zone transition: {from} → {to}"
       - Start rotation immediately on page load with first zone in rotation_order
  </action>

  <done>Frontend loads in browser showing zone rotation with crossfade transitions on configured timing, /api/zones/current returns correct state, config changes update rotation without restart</done>
