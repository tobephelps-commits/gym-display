<task type="auto">
  <name>Task 1: Create project structure and dependencies</name>
  <files>package.json, .gitignore, config.yaml, cache/.gitkeep</files>
  <action>
    1. Create package.json with name "gym-display", version "1.0.0", main "server.js", scripts: { "start": "node server.js", "dev": "node server.js" }
    2. Install dependencies: express, js-yaml, chokidar
    3. Create .gitignore with: node_modules/, cache/*.png, .env, *.log
    4. Create directory structure: services/, public/, cache/, scripts/
    5. Create config.yaml with the full schema from the design document:
       - wodscreen section (url, username, password, refresh_interval_minutes, screenshot_selector)
       - zones section (rotation_order: [wod, video, roster], per-zone durations, boost settings)
       - videos section (array with url, title, enabled — use placeholder URLs)
       - mindbody section (api_key, site_id, source_name, username, password, poll_interval_minutes)
       - system section (port: 3000, log_level: info, timezone: America/Denver, screen_off_start: "22:00", screen_off_end: "04:00")
    6. Create cache/.gitkeep to preserve directory in git
  </action>
  <verify>ls package.json config.yaml .gitignore && node -e "require('./package.json')" && cat config.yaml | head -5</verify>
  <done>package.json valid with all deps installed, config.yaml has full schema, directory structure exists, .gitignore configured</done>
</task>

<task type="auto">
  <name>Task 2: Create Express server with config loading and hot-reload</name>
  <files>server.js, services/config-loader.js</files>
  <action>
    1. Create services/config-loader.js:
       - loadConfig() reads config.yaml with js-yaml, returns parsed object
       - startWatching() uses chokidar.watch on config.yaml with { persistent: true }
       - On change event: re-read and parse YAML, emit 'config-changed' event (use EventEmitter)
       - Export getConfig() returning current config, onConfigChange(callback) for listeners
       - Handle YAML parse errors gracefully — log error, keep previous valid config
       - Handle file not found — log error, exit with code 1

    2. Create server.js:
       - Import express and config-loader
       - Initialize config loader, start watching
       - Serve static files from public/ directory
       - GET /api/config — returns sanitized config (strip credentials: remove wodscreen.password, mindbody.password, mindbody.api_key). Return zones, videos (url+title+enabled only), system settings
       - GET /api/health — returns { status: "ok", uptime: process.uptime() }
       - Listen on config.system.port (default 3000), bind to 0.0.0.0 for development (design doc says localhost-only for Pi, but 0.0.0.0 is fine for dev — deployment phase will lock to 127.0.0.1)
       - Log startup: "Gym Display server running on port {port}"
       - Log config reload events: "Config reloaded"
  </action>
  <verify>npm start & sleep 2 && curl -s http://localhost:3000/api/health && curl -s http://localhost:3000/api/config | node -e "const d=require('fs').readFileSync('/dev/stdin','utf8');const j=JSON.parse(d);console.log('zones:',!!j.zones,'videos:',!!j.videos)" && kill %1</verify>
  <done>/api/health returns ok, /api/config returns zones and videos without credentials, config-loader watches for changes and re-parses on file modification</done>
</task>
