<task type="auto">
  <name>Task 1: Create LeaderboardService that reads team data from Sheets</name>
  <files>services/leaderboard-service.js</files>
  <action>
Create `services/leaderboard-service.js` following the singleton pattern used by video-manager.js and reels-fetcher.js.

**Sheets tab structure** (document in config.example.yaml):
The "Leaderboard" tab has columns: `Name`, `Team`, `Points`
- Name: member display name (e.g., "Alice")
- Team: one of "Green", "Blue", "Red" (case-insensitive)
- Points: numeric point value (string from Sheets, parse to int)

**Service responsibilities:**
- Import `sheetsClient` from `./sheets-client`
- Import `configLoader` from `./config-loader`
- `_refreshFromSheets()` method:
  - Call `sheetsClient.getTabData('Leaderboard')` to get array of row objects
  - Group rows by team (normalize team name: trim, capitalize first letter)
  - For each team: collect members `{name, points}`, calculate team total
  - Sort teams by total descending (1st place first)
  - Sort members within each team by points descending
  - Store result in `this._leaderboard`
- `getLeaderboard()` returns:
  ```json
  {
    "active": true,
    "teams": [
      {
        "name": "Red",
        "color": "#e53e3e",
        "total": 150,
        "rank": 1,
        "members": [
          {"name": "Dave", "points": 80},
          {"name": "Eve", "points": 70}
        ]
      },
      {
        "name": "Green",
        "color": "#38a169",
        "total": 120,
        "rank": 2,
        "members": [...]
      },
      {
        "name": "Blue",
        "color": "#3182ce",
        "total": 90,
        "rank": 3,
        "members": [...]
      }
    ],
    "lastUpdated": "2026-02-23T..."
  }
  ```
- `active` is `false` when Sheets not configured OR Leaderboard tab missing/empty
- When `active` is false, `teams` is empty array
- Color mapping: Green → #38a169, Blue → #3182ce, Red → #e53e3e (hardcoded, matching CONTEXT.md)
- Refresh on a 60-second interval (same pattern as video-manager Sheets sync) — call `_refreshFromSheets()` periodically
- `isActive()` convenience method returning boolean
- Skip rows with missing Name or Team fields (log warning)
- Parse Points as integer, default to 0 if missing/NaN
- Config hot-reload: listen for config changes via `configLoader.onConfigChange()`
- Constructor: initialize empty state, set up refresh interval, do initial refresh
