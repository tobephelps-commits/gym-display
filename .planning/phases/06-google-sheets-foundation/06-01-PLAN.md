<task type="auto">
  <name>Task 1: Install dependencies and create SheetsClient service</name>
  <files>package.json, services/sheets-client.js, config.example.yaml</files>
  <action>
1. Install dependencies:
   ```
   npm install google-spreadsheet google-auth-library
   ```

2. Add `sheets` section to `config.example.yaml` (after the `instagram` section, before `system`):
   ```yaml
   # Google Sheets Integration (data hub for leaderboard, announcements, playlists)
   sheets:
     spreadsheet_id: "your_spreadsheet_id"
     service_account_email: "your-service@project-id.iam.gserviceaccount.com"
     credentials_file: "/home/BigBarn/secrets/google-credentials.json"
     poll_interval_minutes: 5
   ```
   Use `credentials_file` path to the JSON key file (avoids private key newline issues in YAML — see research pitfall #2).

3. Create `services/sheets-client.js` following the **exact pattern** of `services/mindbody.js`:
   - Singleton class `SheetsClient`, exported as `module.exports = new SheetsClient()`
   - Constructor: call `_loadCredentials()`, init `cachedData = {}` (keyed by tab name), `lastPoll = null`, `polling = false`, `_interval = null`, `_doc = null`
   - Register `configLoader.onConfigChange(() => this._loadCredentials())`
   - `_loadCredentials()`: read from `configLoader.getConfig().sheets` — extract `spreadsheet_id`, `service_account_email`, `credentials_file`, `poll_interval_minutes` (default 5)
   - `_isConfigured()`: return true if `spreadsheet_id` exists and isn't placeholder, AND `credentials_file` exists and isn't placeholder
   - `_createAuth()`: Read the JSON key file with `require('fs').readFileSync(this.credentialsFile)`, parse it, create `new JWT({ email: creds.client_email, key: creds.private_key, scopes: ['https://www.googleapis.com/auth/spreadsheets.readonly'] })`. Cache the parsed creds to avoid re-reading the file every poll.
   - `async poll()`: If not configured, return silently. Create `new GoogleSpreadsheet(this.spreadsheetId, this._createAuth())`, call `await doc.loadInfo()`, iterate `doc.sheetsByIndex` to discover all tabs. For each tab, call `await sheet.getRows()` and store as `this.cachedData[tabTitle] = rows.map(row => row.toObject())`. Set `this.lastPoll = Date.now()`. Wrap in try/catch — on error, `console.warn('[Sheets] Poll failed: ...')` and keep stale cache.
   - `startPolling()`: If not configured, log `[Sheets] Not configured, skipping` and return. Call `this.poll()` immediately (with 5-second delay to avoid cold-start quota spike — use `setTimeout`). Then `this._interval = setInterval(() => this.poll(), this.pollIntervalMinutes * 60 * 1000)`. Set `this.polling = true`.
   - `stopPolling()`: Clear interval, set polling false.
   - `getTabData(tabName)`: Return `this.cachedData[tabName] || []`
   - `getTabNames()`: Return `Object.keys(this.cachedData)`
   - `getStatus()`: Return `{ configured: this._isConfigured(), polling: this.polling, lastPoll: this.lastPoll, tabs: this.getTabNames() }`

IMPORTANT: Use `require()` not `import` — this project is CommonJS throughout. The `google-spreadsheet` v5 package supports CJS `require()`.
  </action>

    - `npm ls google-spreadsheet` shows installed

<task type="auto">
  <name>Task 2: Wire SheetsClient into server and add API endpoints</name>
  <files>server.js</files>
  <action>
1. Import sheets-client in server.js alongside existing service imports:
   ```javascript
   const sheetsClient = require('./services/sheets-client');
   ```

2. Add API endpoints (group with existing API routes):
   - `GET /api/sheets/status` — returns `sheetsClient.getStatus()` (configured, polling, lastPoll, tabs)
   - `GET /api/sheets/data/:tab` — returns `{ tab: req.params.tab, data: sheetsClient.getTabData(req.params.tab), count: data.length }`. Return 404 if tab not found in cached data.
   - `GET /api/sheets/tabs` — returns `{ tabs: sheetsClient.getTabNames() }`

3. Initialize polling at server start (same pattern as MindBody — best-effort, non-fatal):
   ```javascript
   // Start Google Sheets polling (best-effort — server works without it)
   sheetsClient.startPolling();
   ```
   Place after existing MindBody initialization.

4. Add `sheets.configured` boolean to the existing `GET /api/config` sanitized response (same pattern as `mindbody.configured`).

5. Do NOT add sheets data to the frontend zone rotation yet — that's for Phases 7-9. This phase only establishes the backend foundation.
