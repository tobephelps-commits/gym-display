  <name>Task 1: Create BriefExtractor service</name>
  <files>services/brief-extractor.js</files>
  <action>
Create a new `BriefExtractor` class that extracts the daily workout brief YouTube video from BTWB and writes it to the Sheets Playlist tab.

**Constructor:** Accept `wodScraper` and `sheetsClient` as dependencies (same DI pattern as live-event-service.js). Store references and initialize state: `_lastVideoUrl`, `_lastExtractDate`, `_enabled` (from config).

**`async extractAndInject()` method — the core flow:**

1. **Guard checks:** Return early if:
   - Config `wodscreen.brief_enabled` is explicitly `false`
   - WodScraper has no browser (`this._wodScraper.browser` is null)
   - WodScraper has no cookies (`this._wodScraper.cookies.length === 0`)
   - SheetsClient is not configured (`!this._sheetsClient._isConfigured()`)
   Log reason at INFO level for each skip.

2. **Open a new Puppeteer page** within WodScraper's existing browser instance (`this._wodScraper.browser.newPage()`). Always close in a `finally` block to prevent Pi memory leaks.

3. **Set BTWB cookies on the new page:** Filter `this._wodScraper.cookies` to only BTWB-domain cookies (`cookie.domain` includes 'beyondthewhiteboard'`). Use `page.setCookie(...btwbCookies)`.

4. **Navigate to the configurable BTWB workout page:** Read URL from `config.wodscreen.brief_url` with fallback to `'https://beyondthewhiteboard.com/members/workouts'`. Use `waitUntil: 'networkidle2'` with 30s timeout. Wrap navigation in try/catch — if BTWB is down, log warning and return null.

5. **Check for login redirect:** If `page.url()` includes 'signin' or 'login', log warning "BTWB session expired for brief extraction" and return null. Don't retry — the WodScraper daily re-login will fix this.

6. **Wait for content to render:** BTWB is a React SPA. Use `page.waitForSelector('iframe, [class*="workout"], [class*="narrative"], .track-detail', { timeout: 15000 }).catch(() => {})` — don't fail if selector not found, proceed to extraction strategies anyway.

7. **Extract YouTube URL using three strategies in priority order:**
   ```javascript
   const videoUrl = await page.evaluate(() => {
     // Strategy 1: YouTube iframe src
     const iframe = document.querySelector('iframe[src*="youtube.com"], iframe[src*="youtu.be"]');
     if (iframe) return iframe.src;

     // Strategy 2: YouTube link href
     const link = document.querySelector('a[href*="youtube.com/watch"], a[href*="youtu.be/"]');
     if (link) return link.href;

     // Strategy 3: Regex scan of page HTML
     const html = document.body.innerHTML;
     const match = html.match(/https?:\/\/(?:www\.)?(?:youtube\.com\/(?:watch\?v=|embed\/)|youtu\.be\/)([\w-]{11})/);
     if (match) return match[0];

     return null;
   });
   ```
   Log which strategy succeeded (or that none found a video).

8. **Handle extraction result:**
   - If `videoUrl` is null: Log at INFO "No brief video found for today" — this is normal (rest days, some programming). If a previous brief row exists in Sheets and is >24h old (check `_lastExtractDate`), disable it by setting enabled=FALSE. Return.
   - If `videoUrl` matches `_lastVideoUrl`: Log "Brief video unchanged" and return (no Sheets write needed).
   - If `videoUrl` is new: Proceed to Sheets write.

9. **Normalize the YouTube URL:** Strip embed parameters. If URL is `youtube.com/embed/VIDEO_ID`, convert to `youtube.com/watch?v=VIDEO_ID`. Use the existing `extractYouTubeId()` pattern from video-manager.js to validate it's a real YouTube ID (11 chars).

10. **Write to Sheets Playlist tab** using `_writeBriefToPlaylist(videoUrl)`:
    - Create auth and GoogleSpreadsheet doc instance using the same pattern as sheets-client.js `writeInstructionsTab()` — call `this._sheetsClient._createAuth()` and use the spreadsheet ID from config.
    - Load the Playlist sheet. If no Playlist tab exists, log warning and return.
    - Get all rows. Find existing row where `title` column equals the sentinel value `[Daily Brief]`.
    - If found and URL changed: `row.set('url', videoUrl)`, `row.set('enabled', 'TRUE')`, `await row.save()`.
    - If found and URL same: No-op.
    - If not found: `await sheet.addRow({ url: videoUrl, title: '[Daily Brief]', enabled: 'TRUE', days: '', focus: config.wodscreen.brief_focus !== false ? 'TRUE' : 'FALSE' })`.
    - Update `_lastVideoUrl` and `_lastExtractDate`.

**`getStatus()` method:** Return `{ enabled, lastVideoUrl, lastExtractDate, sheetsConfigured }` for the admin status API.

**Error handling:** The entire `extractAndInject()` call should be wrapped so failures are non-fatal. Log errors at WARN level with `[BriefExtractor]` prefix. Never throw — this must not disrupt the WOD scrape cycle.

**Module export pattern:** Export a factory function `create(wodScraper, sheetsClient)` that returns a new BriefExtractor instance (same pattern as live-event-service.js).
