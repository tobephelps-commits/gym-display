<task type="checkpoint:human-action" gate="blocking">
  <action>Update MindBody production credentials in config.yaml on the Pi</action>
  <instructions>
    The Pi's config.yaml currently has sandbox MindBody credentials. You need to replace them with production values.

    1. SSH into the Pi:
       ```
       ssh BigBarn@100.120.21.22
       ```

    2. Edit config.yaml:
       ```
       nano ~/gym-display/config.yaml
       ```

    3. Update the mindbody section with your production credentials:
       ```yaml
       mindbody:
         api_key: "YOUR_PRODUCTION_API_KEY"
         site_id: "YOUR_REAL_SITE_ID"
         source_name: "YOUR_SOURCE_NAME"
         username: "YOUR_STAFF_EMAIL"
         password: "YOUR_STAFF_PASSWORD"
       ```

    4. Save and exit (Ctrl+X, Y, Enter)

    5. Restart the service:
       ```
       sudo systemctl restart gym-display
       ```

    6. Check logs for MindBody auth success:
       ```
       journalctl -u gym-display -f --no-pager | head -30
       ```
       Look for successful MindBody token fetch (no auth errors).
  </instructions>
  <verification>journalctl shows MindBody token acquired without errors</verification>
  <resume-signal>Type "done" when credentials are updated and service restarted, or describe any errors you see in the logs</resume-signal>
