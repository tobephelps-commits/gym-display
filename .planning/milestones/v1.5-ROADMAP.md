# Milestone v1.5: Live Events

**Status:** SHIPPED 2026-02-26
**Phases:** 17
**Total Plans:** 2

## Overview

Enable full-screen YouTube Live takeover for competition events, controlled via Google Sheets scheduling. When a live event is active, the display switches from normal five-zone rotation to fullscreen YouTube Live, automatically resuming when the event ends.

## Phases

### Phase 17: Live Event Override

**Goal**: Sheets tab polling for live event scheduling, rotation engine override to show YouTube Live fullscreen, automatic resume when event ends, admin panel event visibility
**Depends on**: Previous milestone complete (v1.4)
**Plans**: 2 plans

Plans:

- [x] 17-01: LiveEventService + Server Integration (2/2 tasks) — completed 2026-02-26
- [x] 17-02: Frontend Live Event Zone + Admin Status (2/2 tasks) — completed 2026-02-26

**Details:**

**Plan 17-01: LiveEventService + Server Integration**
- Created `services/live-event-service.js` — polls Sheets "LiveEvent" tab every 60s, timezone-aware event detection, YouTube video ID extraction from multiple URL formats
- ZoneController override: `getZoneState()` returns `currentZone: 'live-event'` with `durationMs: 0` when event active
- Server routes: `GET /api/live-event` (public), `POST /api/admin/refresh/live-event` (admin), `liveEvent` in admin status
- Config loader: added `'live-event'` to valid zone names
- Factory export pattern: `module.exports.create(sheetsClient, configLoader)`

**Plan 17-02: Frontend Live Event Zone + Admin Status**
- Frontend: fullscreen YouTube Live zone with title overlay (fades after 10s), rotation pause/resume
- Admin dashboard: Live Event card with LIVE NOW (red pulse), Scheduled (yellow), No Event (gray) badges
- Sheets Instructions: LiveEvent tab documentation for coaches (columns, behavior, examples)
- Auto-creates LiveEvent tab with column headers in Google Sheets on first run

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**

- Timezone parsing uses `Intl.DateTimeFormat` with iterative offset correction for "YYYY-MM-DD HH:MM" format
- YouTube ID regex extended to support `youtube.com/live/` URLs for live streams
- Live event zone returns `durationMs: 0` — no auto-advance, stays until server says event ended
- First-match wins for overlapping events (top row in Sheets)
- No YT `onStateChange` handler — live streams don't end via player state; server controls the window
- Overlay fade timeout of 10 seconds for title readability without distraction
- Auto-create LiveEvent tab with headers on first Sheets poll
