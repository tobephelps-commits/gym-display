# Milestone v1.1: Command Center

**Status:** ✅ SHIPPED 2026-02-23
**Phases:** 6-10
**Total Plans:** 10

## Overview

Google Sheets as central data hub, two new rotation zones (leaderboard + announcements), web admin panel, and Instagram fix. Transforms the gym display from a static configuration system to a coach-friendly, Sheets-driven content management platform with browser-based administration.

## Phases

### Phase 6: Google Sheets Foundation

**Goal**: Set up Google Sheets API auth (service account), build API client, establish single Sheet with multiple tabs pattern
**Depends on**: v1.0 milestone complete
**Plans**: 1 plan

Plans:

- [x] 06-01: Google Sheets Client & API Endpoints

**Details:**
- Created SheetsClient singleton with service account JWT auth and credential file loading
- Implemented polling with configurable interval, 5-second initial delay, stale-cache-on-error
- Added `/api/sheets/status`, `/api/sheets/tabs`, `/api/sheets/data/:tab` endpoints
- Config hot-reload support matching MindBody singleton pattern
- Graceful degradation when Sheets not configured

### Phase 7: Playlist Sync + Instagram Fix

**Goal**: Replace config.yaml video playlist with Google Sheets tab; fix Instagram rate-limiting so reels refresh automatically on Pi
**Depends on**: Phase 6
**Plans**: 2 plans

Plans:

- [x] 07-01: Sheets-Driven YouTube Playlist
- [x] 07-02: Instagram Fix via Sheets URLs + yt-dlp

**Details:**
- VideoManager reads Sheets "Playlist" tab first, falls back to config.yaml
- 60-second periodic sync detects Sheets changes automatically
- ReelsFetcher downloads non-YouTube URLs via yt-dlp with MD5 filename hashing
- Graceful yt-dlp availability check; instaloader fallback when Sheets not configured
- Stale reel pruning tracks URL-to-filename mapping

### Phase 8: Team vs Team Leaderboard Zone

**Goal**: New rotation screen showing competing teams with individual member points; coaches enter points manually in Google Sheets tab
**Depends on**: Phase 6
**Plans**: 2 plans

Plans:

- [x] 08-01: LeaderboardService Backend + API + Zone Integration
- [x] 08-02: Leaderboard Frontend Zone

**Details:**
- LeaderboardService reads Sheets "Leaderboard" tab, groups by team, calculates totals and ranks
- GET /api/leaderboard serves structured team standings with members, points, colors
- Frontend: dark charcoal background, three color-coded team cards (Green/Blue/Red), rank badges, 5rem scores
- 30-second poll while displayed, auto-skip when unconfigured
- Responsive density classes for member lists (normal/compact/dense)

### Phase 9: Announcements Zone

**Goal**: New rotation screen that appears when announcements exist in Sheets tab; disappears from rotation when no active announcements
**Depends on**: Phase 6
**Plans**: 2 plans

Plans:

- [x] 09-01: AnnouncementsService Backend + API + Zone Integration
- [x] 09-02: Announcements Frontend Zone

**Details:**
- AnnouncementsService reads Sheets "Announcements" tab, filters active rows, sorts by priority (urgent first)
- GET /api/announcements serves announcement data with active status and count
- Frontend: deep navy background, card layout with urgent (red border + glow) and normal (blue border) styling
- Compact mode for >4 announcements, 30-second poll, auto-skip when empty

### Phase 10: Web Admin Panel

**Goal**: Browser-based UI to manage config, playlists, settings, and view system status without SSH access to the Pi
**Depends on**: Phase 7, Phase 8, Phase 9
**Plans**: 3 plans

Plans:

- [x] 10-01: Admin Panel Foundation (Backend + HTML Shell)
- [x] 10-02: Status Dashboard with Live Polling
- [x] 10-03: Settings Page with Config Editor

**Details:**
- Bearer token auth middleware with open-access default for local Pi

## Milestone Summary

**Key Decisions:**

- Sheets credentials_file path approach (not inline private key) — avoids YAML newline escaping
- 5-second initial poll delay — avoids Google API cold-start quota spike
- Reels source priority: Sheets Playlist tab via yt-dlp first, instaloader fallback
- MD5(url) filename hashing for stable reel filenames across fetch cycles
- 60-second refresh interval for Sheets-based services (leaderboard, announcements, playlist)
- Hardcoded team colors: Green #38a169, Blue #3182ce, Red #e53e3e
- Announcements two-tier priority sort: urgent first, then normal
- Admin open access by default (no auth when admin_token not configured)
- Per-section save in admin settings — avoids accidental cross-section changes
- Config backup on save — automatic one-level backup (config.yaml.bak)

**Issues Resolved:**

- Instagram rate-limiting from Pi IP — replaced instaloader scraping with yt-dlp downloading from Sheets URLs
- Static playlist management — replaced config.yaml-only playlist with Sheets-driven sync

**Issues Deferred:**

- yt-dlp needs to be installed on Pi (`pip3 install yt-dlp`)
- Google Sheets setup (service account, credentials file) still pending
- MindBody production API key still needed (using sandbox credentials)

**Technical Debt Incurred:**

- Admin dashboard JS is inline in index.html (tightly coupled to DOM, could be extracted later)
- No admin panel tests (utility panel, function over form)
- Single-level config backup only (no version history)
